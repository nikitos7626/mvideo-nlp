# product-attribute-extractor

Сервис автоматического извлечения и нормализации характеристик товаров из неструктурированных описаний селлеров для маркетплейсов и e-commerce.

---

## Быстрый запуск

### Вариант 1. Запуск через Docker

```bash
docker compose up --build
```

Доступные интерфейсы после запуска:
* Веб-интерфейс: [http://localhost:8000](http://localhost:8000)
* Документация OpenAPI / Swagger: [http://localhost:8000/docs](http://localhost:8000/docs)
* Эндпоинт извлечения: `POST http://localhost:8000/api/extract`
* Проверка состояния: `GET http://localhost:8000/health`

---

### Вариант 2. Локальный интерактивный режим (CLI)

Позволяет проверить работу пайплайна на произвольном тексте карточки прямо в терминале:

```bash
python interactive.py
```

---

### Вариант 3. Запуск тестов

```bash
python -m pytest
```

## Архитектура решения

Пайплайн построен по принципу 4-этапного каскада (Cascaded Extraction):

1. **Category Detector:** определение категории товара (смартфоны, ноутбуки, ТВ, пылесосы, холодильники и др.) и подгрузка целевой таксономии каталога товаров.
2. **Tier 1 (FlashText + Regex):** детерминированное извлечение брендов, цветов и числовых характеристик (память, экран, батарея, частота) со временем обработки < 1 мс на карточку.
3. **Tier 2 (GLiNER Zero-Shot NER):** локальное доизвлечение недостающих сущностей на CPU (`urchade/gliner_multi-v2.1`): модель/серия, процессор, тип уборки, система разморозки.
4. **AttributeTypeValidator & HITL:** валидация типов (отсечение галлюцинаций), калибровка уверенности (Confidence Score) и маршрутизация карточек с низким баллом операторам на модерацию (`needs_review`).
